Vulnerability Details

Overview

A critical command injection vulnerability exists in the GlobalProtect gateway's HIP (Host Information Profile) check mechanism. The vulnerability allows an unauthenticated attacker to execute arbitrary OS commands on the firewall with root privileges.

Affected Component

The vulnerability is in the /ssl-vpn/hipreport.esp endpoint, which processes HIP reports submitted by GlobalProtect clients during the connection setup phase.

Attack Vector

The SESSID cookie value is passed to a shell command without proper sanitization. An attacker can craft a malicious session identifier containing OS commands to achieve Remote Code Execution (RCE). The endpoint accepts POST requests.

Exploitation

Proof-of-concept exploits are publicly available. The attack requires no authentication. Threat actors (including UTA0218/APT-MIRAGE) have been observed exploiting this vulnerability in the wild to deploy backdoors and exfiltrate data.

Interim Mitigation

Threat Prevention Signature

Threat Prevention signature #95187 has been deployed on the PA-5260 to detect exploitation attempts. However, bypass techniques have been observed — treat this as a partial mitigation only.

Monitoring

SOC is monitoring for suspicious activity on the /ssl-vpn/ path. Any unusual command execution or file access under /opt/panlogs/ should be reported immediately to the IR team.
